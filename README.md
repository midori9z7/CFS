# CFS
learning C from scratch.

## Levels

- [noob-level](noob-level/README.md) — from zero to a working calculator:
  10 lessons, small projects, and a build script.
- [beginner-level](beginner-level/README.md) — from pointers to a tiny dungeon:
  pointers, structs, dynamic memory, files, recursion; 10 lessons and
  8 projects.

## Standalone projects

- `projects/scrnsaver1.c`, `projects/infinite_ring.c` — screensaver
  experiments. More advanced than the current levels; treat them as goals
  for the later levels.
Just for fun XD
